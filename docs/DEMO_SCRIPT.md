# Démonstration en cinq étapes

Les résultats de cette version sont dans [RESULTATS.md](RESULTATS.md). Les captures `docs/img/` proviennent de l'ancienne version et doivent être remplacées avant une présentation publique.

| Étape | Manipulation | Formulation défendable |
|---|---|---|
| Le verrou | Montrer rendements et importations | La variabilité du rendement motive une comparaison explicite des risques. |
| Le prix | Saisir une offre hypothétique, puis faire varier le prix rendu | Le transport est déduit pour obtenir le prix départ ferme. La courbe montre une fréquence simulée sur un trajet de référence, pas une garantie individuelle. |
| L'épreuve | Rejouer les chocs 2016 et 2020 sur les parcelles du scénario | Ce stress applique un choc national passé au rendement lentille simulé. Ce ne sont pas les marges historiques réelles des exploitations. |
| La preuve | Choisir un département ; comparer toutes les méthodes | Une couverture élevée ou un taux de succès élevé ne prouve pas une décision moins coûteuse. Montrer prix, coût et pertes. |
| Le contrat | Modifier revente, pertes au tri, coûts, marge et offre | Un accord existe seulement si le prix requis pour le volume attendu entre dans le plafond acheteur. Il est possible que l'outil conclue « impossible ». |

Une seule campagne 2026. Volume attendu, non garanti. Aide non confirmée exclue. La référence de lentille 2012–2016 est nominale et ancienne ; elle n'est jamais une cotation actuelle. La sélection automatique peut retenir M0 sans météo : le résultat doit être montré tel quel.
